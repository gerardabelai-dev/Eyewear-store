# Screenshots Guide

Add the following screenshots to this folder to complete the README documentation.

## Required Screenshots

### Hero Image
- **Filename:** `hero.png`
- **Description:** Main hero image showing the homepage with product highlights
- **Suggested dimensions:** 1200x630px (optimized for social sharing)

### Customer Storefront

| Filename | Description | Suggested View |
|----------|-------------|----------------|
| `catalog.png` | Product catalog/listing page | Grid of products with filters |
| `product-details.png` | Single product page | Product with images, price, lens options |
| `cart.png` | Shopping cart | Cart with multiple items and summary |

### Checkout Flow

| Filename | Description | Suggested View |
|----------|-------------|----------------|
| `checkout.png` | Checkout page | Multi-step accordion with customer info |
| `payment.png` | Payment step | Stripe card input form |

### Admin Panel

| Filename | Description | Suggested View |
|----------|-------------|----------------|
| `admin-dashboard.png` | Admin dashboard | Overview with stats/metrics |
| `admin-orders.png` | Orders management | Orders table with status filters |
| `admin-products.png` | Products management | Products table with edit actions |

## Tips for Screenshots

1. **Use a clean browser** - Hide bookmarks bar, use incognito mode
2. **Consistent dimensions** - Try to keep all screenshots the same width
3. **Light/Dark mode** - Consider providing both versions
4. **Sample data** - Use realistic-looking sample data
5. **Highlight features** - Show the most important UI elements

## Recommended Tools

- [CleanShot X](https://cleanshot.com/) (macOS)
- [Greenshot](https://getgreenshot.org/) (Windows)
- [Flameshot](https://flameshot.org/) (Linux)
- Browser DevTools screenshot (Cmd/Ctrl + Shift + P → "Screenshot")

## Adding to README

Once you've added the screenshots, uncomment the image tags in the main `README.md` file:

```markdown
<!-- Before -->
<!-- ![Product Catalog](./docs/screenshots/catalog.png) -->

<!-- After -->
![Product Catalog](./docs/screenshots/catalog.png)
```
